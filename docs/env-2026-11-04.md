## 性能基准（2026-11-04 实测）

| 测试 | 结果 |
|------|------|
| bf16 matmul 4096³ | 0.92 ms/iter → **148.6 TFLOPS** |
| fp16 matmul 4096³ | 0.83 ms/iter → **166.4 TFLOPS** |
| TinyNet 训练（bs=64, 64×64） | 91.6 step/s，显存峰值 0.11 GiB |

> ⚠️ **冷卡陷阱**：开机第一次测 matmul 会得到 12 TFLOPS 左右的假数据，
> 因为 GPU 还在 P8 低功耗状态。必须预热 10 次以上再计时。

## 使用方式

```bash
# 交互式 SSH 登录后，.bashrc 会自动激活 py310
ssh -p <端口> root@<地址>

# 非交互式命令（如脚本调用）必须手动激活
source /usr/local/miniconda3/bin/activate py310
```

## 开机自检

```bash
python scripts/smoke_train.py    # 30 秒：算力 + 前向反向 + 显存
python scripts/check_gpu.py      # 逐项检查，适合排查问题
```

## 已配置

- pip 镜像：清华源（写入 `/root/.config/pip/pip.conf`）
- 云端已放置：`/root/check_gpu.py`、`/root/smoke_train.py`
